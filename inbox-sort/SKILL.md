# inbox-sort

`~/Desktop/brain/inbox.md`에 던져둔 메모를 볼트 규칙(`INDEX.md`)에 맞는 자리로 보낸다. **제안 → 승인 → 이동** 순서를 반드시 지킨다.

## 1. 읽기

1. `INDEX.md`의 "폴더 구조"와 "현재 진행 중인 프로젝트"만 읽는다(전체 볼트를 훑지 않는다).
2. `inbox.md`를 읽는다. 비어 있으면 "inbox 비어 있음" 한 줄로 끝.
3. 항목 단위로 나눈다: 불릿/체크박스 한 줄 = 항목 하나, 빈 줄로 구분된 문단 = 항목 하나. 들여쓴 하위 줄은 위 항목에 포함.
4. 항목마다 키워드로 볼트를 검색(`grep -ril`)해서 관련 노트가 있는지 확인한다.

## 2. 분류 기준

판단 질문은 "이건 지금 하고 있는 일과 어떻게 연결되나?"

| 목적지 | 언제 |
|---|---|
| `projects/<이름>/` 기존 노트 | 특정 프로젝트의 아이디어·할 일·결정 |
| `projects/<이름>/` 새 노트 | 기존 노트에 맞는 곳이 없고 내용이 3줄 이상 |
| `school/<과목>/` | 수업·과제·시험 관련 |
| `resources/concepts/` 새 개념 노트 | 여러 곳에서 재사용할 지식·인사이트 (`_templates/개념 노트.md` 양식) |
| `resources/overview.md` 링크 목록 | 나중에 볼 외부 링크·자료 |
| `daily/<날짜>.md` | 그날 한 일 기록에 가까운 것 |
| 새 프로젝트 후보 | 어느 프로젝트에도 안 맞는 새 아이디어 — **폴더를 만들지 말고** 사용자에게 물어본다 |
| 그대로 둠 | 맥락이 부족해 판단 불가 |

확신이 없으면 "그대로 둠"으로 분류하고 이유를 적는다.

## 3. 제안 (여기서 멈춘다)

번호 붙은 표로 보여준다:

| # | 메모 (앞 40자) | → 목적지 | 방식 | 이유 |
|---|---|---|---|---|
| 1 | 강아지 채팅 다마고치처럼 | projects/dog-adoption/빠른 메모.md | 끝에 추가 | 입양 서비스 기능 아이디어 |

끝에 "옮길 번호를 알려주세요 (전부면 '전부', 목적지 바꾸려면 '3번은 school로')"라고 묻고 **승인 전에는 아무 파일도 수정하지 않는다.**

## 4. 이동 (승인된 항목만)

- **기존 노트에 추가**: 노트 끝(또는 `## 메모` 섹션이 있으면 그 안)에 `- (YYYY-MM-DD) 내용` 형식으로 붙인다. 기존 내용은 바꾸지 않는다.
- **새 노트**: 맨 위에 허브로 돌아가는 링크(`← [[경로/overview|… 개요로]]`)를 넣고, 허브 노트 목록에도 새 노트 링크를 추가한다. 개념 노트는 `resources/overview.md` 목록에 추가하고 출처·연결 칸을 채운다.
- **daily**: 해당 날짜 파일이 없으면 `_templates/daily.md` 양식으로 만든다.
- **inbox.md에서는 옮긴 항목만 지운다.** "그대로 둠"과 승인 안 된 항목은 남긴다. inbox.md 파일 자체는 절대 삭제하지 않는다.
- 옮기기 전에 원본 inbox 내용을 `/tmp/inbox-backup-<시각>.md`에 복사해 둔다.
- `.obsidian/`은 건드리지 않는다. 새 프로젝트 폴더가 생기면 INDEX.md에 링크하고 `graph-colorize` 실행을 안내한다.
